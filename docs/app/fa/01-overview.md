# بخش ۱ — نمای کلی پروژه

## هدف

**توپ‌سِت (ToopSet)** یک پلتفرم آنلاین رزرو زمین‌های ورزشی برای شهر قم، ایران است. کاربران نهایی می‌توانند مجموعه‌های ورزشی را کشف کنند، سانس‌ها را با موجودی بلادرنگ رزرو کنند، پرداخت انجام دهند (درگاه شبیه‌سازی شده)، نظر ثبت کنند و کیف پول خود را مدیریت کنند. مدیران مجموعه‌ها، مکان‌ها را ثبت و سانس‌ها را مدیریت می‌کنند. ادمین سیستم بر کاربران نظارت می‌کند، مجموعه‌ها را تأیید می‌کند، تسویه‌حساب‌ها را مدیریت می‌کند و پلتفرم را مانیتور می‌کند.

## دامنه کسب‌وکار

- **موجودیت اصلی:** یک "مجموعه ورزشی" (Vendor) که "سانس‌های" (Time Slots) قابل رزرو ارائه می‌دهد
- **جریان اصلی:** کاربر مجموعه را پیدا می‌کند ← سانس انتخاب می‌کند ← رزرو ایجاد می‌کند (مهلت پرداخت ۱۰ دقیقه) ← پرداخت می‌کند ← رزرو تأیید می‌شود
- **جریان‌های فرعی:** لغو با جریمه پلکانی، رزرو حضوری توسط مدیر، تسویه‌حساب با مدیران، ورود با OTP بدون رمز عبور، بازگشت وجه به کیف پول
- **ویژگی‌های بازار ایران:** رابط فارسی-اول، تقویم شمسی، شماره موبایل ایرانی (`۰۹XXXXXXXXX`)، سانس‌های تفکیک جنسیتی، نقشه محدود به قم

## فرضیات استقرار

- **توسعه:** `compose.yml` PostgreSQL و Redis را به‌صورت محلی فراهم می‌کند؛ بک‌اند با `uvicorn`، فرانت‌اند با `next dev` اجرا می‌شود
- **تولید:** Dockerfile چند مرحله‌ای برای بک‌اند (Python 3.12-slim، کاربر غیر root)؛ بیلد standalone Next.js؛ هماهنگی با `compose.prod.yml`
- **CI:** GitHub Actions لینت/تست بک‌اند را روی PR و بیلد Docker image را روی tag اجرا می‌کند
