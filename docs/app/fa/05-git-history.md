- بازطراحی صفحه تنظیمات با مدیریت کارت بانکی
- جریان ورود/ثبت‌نام مبتنی بر OTP با تأیید دو مرحله‌ای

**تصمیمات معماری:**
- سیاست لغو پلکانی (قانون کسب‌وکار: ≤۴۸ ساعت حالت انتظار جایگزین می‌گیرد، نه بازگشت وجه فوری)

**مبادلات:**
- کامیت بزرگ یکپارچه، "یک تغییر منطقی به ازای هر کامیت" را نقض می‌کند — چندین ویژگی باهم بسته‌بندی شده‌اند
