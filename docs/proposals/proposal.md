## ۱. عنوان پروژه

**ToopSet — سامانه رزرو آنلاین مجموعه‌های ورزشی با رویکرد معماری مدرن وب (FastAPI + Next.js)**

---

## ۲. چکیده

امروزه با گسترش فناوری‌های وب و افزایش تقاضا برای خدمات آنلاین، لزوم ایجاد سامانه‌های یکپارچه و کاربرپسند برای مدیریت و رزرو اماکن ورزشی بیش از پیش احساس می‌شود. در این پروژه، یک سامانه جامع رزرو آنلاین مجموعه‌های ورزشی با عنوان «توپ‌سِت» (ToopSet) طراحی و پیاده‌سازی شده است. این سامانه با بهره‌گیری از معماری مدرن وب (تکنولوژی‌های FastAPI در سمت سرور و Next.js در سمت کلاینت) امکان جستجو، رزرو، پرداخت و مدیریت مجموعه‌های ورزشی را برای کاربران فراهم می‌کند. همچنین با پیاده‌سازی نقش‌های مختلف کاربری (کاربر عادی، مدیر مجموعه، مدیر سیستم)، سطح‌بندی دسترسی‌ها و وظایف به صورت دقیق انجام شده است.

---

## ۳. بیان مسئله

با افزایش آگاهی عمومی نسبت به سلامت و اهمیت فعالیت‌های ورزشی، تقاضا برای استفاده از مجموعه‌های ورزشی افزایش چشمگیری یافته است. با این حال، فرآیند رزرو مجموعه‌های ورزشی در بسیاری از موارد به صورت سنتی (تماس تلفنی، مراجعه حضوری) انجام می‌شود که با چالش‌های زیر همراه است:

1. **عدم شفافیت در زمان‌های خالی:** کاربران نمی‌توانند به راحتی از زمان‌های آزاد مجموعه‌ها مطلع شوند.
2. **دشواری مدیریت برای صاحبان مجموعه:** مدیران مجموعه‌ها برای مدیریت زمان‌بندی و رزروها با سردرگمی مواجه هستند.
3. **عدم یکپارچگی:** سامانه‌های موجود اغلب تنها بخشی از نیازها را پوشش می‌دهند (مثلاً فقط نمایش اطلاعات یا فقط رزرو).
4. **ضعف در پشتیبانی از زبان و فرهنگ فارسی:** بسیاری از سامانه‌های موجود راست‌چین (RTL) نبوده یا محتوای فارسی را به درستی نمایش نمی‌دهند.
5. **عدم پشتیبانی از تقویم شمسی:** بیشتر سامانه‌های خارجی از تقویم میلادی استفاده می‌کنند که برای کاربر ایرانی مناسب نیست.

هدف این پروژه، طراحی و پیاده‌سازی یک سامانه وب کامل و بومی است که تمامی نیازهای فوق را پوشش داده و تجربه‌ای روان و یکپارچه برای کاربران، مدیران مجموعه‌ها و مدیران سیستم فراهم کند.

## ۴. اهداف پروژه

### ۴.۱. اهداف کلی

- طراحی و پیاده‌سازی یک سامانه جامع رزرو آنلاین مجموعه‌های ورزشی با قابلیت‌های کامل مدیریتی
- ارائه معماری نرم‌افزاری ماژولار، مقیاس‌پذیر و قابل نگهداری
- پشتیبانی کامل از زبان و فرهنگ فارسی (راست‌چین، تقویم شمسی، اعداد فارسی)

### ۴.۲. اهداف اختصاصی

1. **سیستم احراز هویت امن:** پیاده‌سازی احراز هویت مبتنی بر JWT با قابلیت تازه‌سازی خودکار توکن و مدیریت نشست‌ها
2. **سیستم رزرو هوشمند:** امکان رزرو زمان‌های ورزشی با مدیریت تداخل‌ها، انقضا و لغو با جریمه
3. **سیستم کیف پول:** مدیریت شارژ، برداشت و بازگشت وجه با یکپارچگی با سیستم رزرو
4. **سیستم مدیریت مجموعه‌ها:** ثبت، ویرایش، تصاویر، تأیید و مدیریت مجموعه‌های ورزشی
5. **سیستم زمان‌بندی پیشرفته:** مدیریت زمان‌های هفتگی با تولید انبوه سانس‌ها و نمایش گرافیکی
6. **سیستم اعلان‌ها:** اطلاع‌رسانی خودکار به کاربران در مورد رزروها و تغییرات
7. **سیستم نظرات و امتیازات:** ثبت و مدیریت نظرات کاربران با قابلیت پاسخ مدیریت
8. **سیستم گزارش‌گیری و آمار:** داشبوردهای تحلیلی برای مدیران مجموعه و مدیران سیستم
9. **سیستم بایگانی رویدادها (Audit Log):** ثبت و پیگیری تمامی رویدادهای مهم سیستم
10. **مدیریت تنظیمات پلتفرم:** امکان پیکربندی پلتفرم توسط مدیر سیستم

## ۶. روش تحقیق و پیاده‌سازی

### ۶.۱. معماری کلی

پروژه از معماری **کلاینت-سرور** با **API محور** پیروی می‌کند. بخش سرور (Backend) به صورت RESTful API طراحی شده و بخش کلاینت (Frontend) با استفاده از فریم‌ورک React و Next.js 16 این API را مصرف می‌کند.

```
Client (Next.js) ←→ REST API (FastAPI) ←→ Database (PostgreSQL)
                                            ↕
                                         Redis (Cache)
```

### ۶.۲. معماری سمت سرور

لایه‌های معماری بک‌اند:

1. **لایه مسیریاب (Router):** تعریف نقاط پایانی HTTP، اعتبارسنجی ورودی و مدیریت مجوزها
2. **لایه سرویس (Service):** منطق کسب‌وکار، هماهنگی فرآیندها و مدیریت تراکنش‌ها
3. **لایه مخزن (Repository):** کوئری‌های پایگاه داده با SQLAlchemy Async
4. **لایه مدل (Model):** مدل‌های ORM پایگاه داده
5. **لایه اعتبارسنجی (Schema):** مدل‌های Pydantic برای اعتبارسنجی ورودی و خروجی

همچنین مؤلفه‌های زیر به صورت سرویس‌های عمومی طراحی شده‌اند:

- سامانه احراز هویت (JWT با قابلیت تازه‌سازی)
- محدودسازی نرخ درخواست (Rate Limiting) با Redis
- لاگ رویدادها (Audit Logging)
- آپلود فایل (تصاویر مجموعه و آواتار کاربران)

### ۶.۳. معماری سمت کلاینت

- **مسیریابی:** App Router نکست‌جی‌اس با قابلیت سرویس‌ساید و کلاینت‌ساید رندرینگ
- **مدیریت حالت:** React Hooks (useState, useCallback, useEffect) بدون کتابخانه مدیریت حالت خارجی
- **کامپوننت‌ها:** استفاده از shadcn/ui مبتنی بر Radix UI برای کامپوننت‌های استاندارد و شخصی‌سازی شده
- **استایل‌دهی:** Tailwind CSS v4 با پشتیبانی کامل از RTL
- **درخواست‌های HTTP:** یک کلاینت مرکزی با قابلیت تازه‌سازی خودکار توکن

### ۶.۴. پایگاه داده

پایگاه داده شامل ۱۳ مدل اصلی است:

| مدل               | توضیح                                         |
| ----------------- | --------------------------------------------- |
| User              | کاربران با نقش‌های مختلف (user/manager/admin) |
| Court             | مجموعه‌های ورزشی با اطلاعات مکانی و تصاویر    |
| TimeSlot          | سانس‌های زمانی هر مجموعه                      |
| Booking           | رزروهای ثبت شده توسط کاربران                  |

| Review            | نظرات و امتیازات کاربران                      |
| Wallet            | کیف پول کاربران                               |
| WalletTransaction | تراکنش‌های کیف پول                            |
| Notification      | اعلان‌های کاربران                             |
| Penalty           | جریمه‌های لغو رزرو                            |

### ۶.۵. امنیت

- احراز هویت با JWT (توکن دسترسی ۳۰ دقیقه، توکن تازه‌سازی ۷ روز)
- هش کردن رمز عبور با bcrypt
- محدودسازی نرخ درخواست برای نقاط پایانی حساس (ورود: ۵ بار/دقیقه، ثبت‌نام: ۳ بار/دقیقه)
- اعتبارسنجی ورودی با Pydantic v2
- کنترل دسترسی مبتنی بر نقش (RBAC)

## ۸. قابلیت‌های پیاده‌سازی شده

### کاربران (نقش کاربر عادی)

- ثبت‌نام و ورود با شماره تلفن
- مشاهده و جستجوی مجموعه‌های ورزشی
- مشاهده نقشه مجموعه‌ها
- فیلتر بر اساس نوع ورزش، محدوده قیمت و موقعیت مکانی
- رزرو سانس‌های زمانی
- پرداخت از طریق کیف پول
- ثبت نظر و امتیاز
- مشاهده تاریخچه رزروها
- مدیریت پروفایل و آواتار

### مدیران مجموعه (نقش manager)

- ثبت و مدیریت مجموعه‌های ورزشی
- مدیریت زمان‌بندی هفتگی (جدول گرافیکی)
- تولید انبوه سانس‌ها با قالب‌های زمانی
- ایجاد سانس سریع
- پاکسازی سانس‌های گذشته
- مشاهده گزارش‌ها و آمار

### مدیران سیستم (نقش admin)

- مدیریت کاربران (تغییر نقش، فعال/غیرفعال، حذف)
- مدیریت مجموعه‌ها (تأیید، رد، فعال/غیرفعال)
- مدیریت رزروها (مشاهده و لغو)
- مشاهده لاگ رویدادها (با فیلتر پیشرفته)
- مدیریت پیام‌های تماس
- مدیریت نظرات
- تنظیمات پلتفرم
- اعلان همگانی

## ۱۰. نتیجه‌گیری
